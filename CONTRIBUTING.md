# Contributing to nori

Thank you for helping. Start with the developer docs in `docs/developers/`:

- [Contributing](docs/developers/contributing.md): the checks, the commits and where the docs live.
- [Architecture](docs/developers/architecture.md) and [Writing a client](docs/developers/writing-a-client.md): what the core does and what each app does.
- [Building](docs/developers/building.md) and [Testing](docs/developers/testing.md).

[AGENTS.md](AGENTS.md) is the working agreement for people and agents alike: the commands, the
boundaries, the code rules and the commit format (one line, conventional, no trailers).

Report security problems privately: see [SECURITY.md](SECURITY.md).
