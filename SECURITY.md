# Security

To report a vulnerability in any nori client, report it privately, not in a public issue:

1. On the [repository](https://github.com/norifm/nori), open the **Security** tab.
2. Choose **Report a vulnerability**.
3. Say what you found and how to reproduce it. Name the client and the version it affects.
