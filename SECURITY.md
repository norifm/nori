# Security

Applies to every nori client.

Report a vulnerability privately, not in a public issue:

1. Open the [repository](https://github.com/norifm/nori)'s Security tab.
2. Choose **Report a vulnerability**.
3. Say what you found, how to reproduce it, and which client and version it affects.
